# STACKFAST

This repository is structured so the local STACKFAST project root resolves to:

```text
C:\STACKFAST
```

## Recommended structure

```text
C:\STACKFAST
├── app
├── public
├── components
├── lib
├── styles
├── assets
├── agents
├── workflows
├── prompts
├── package.json
├── next.config.js
└── README.md
```

## Local development

If you are using the existing project structure from the earlier setup, open a terminal and run:

```powershell
cd C:\STACKFAST
npm install
npm run dev
```

The Vercel-ready root path is:

```text
C:\STACKFAST
```
