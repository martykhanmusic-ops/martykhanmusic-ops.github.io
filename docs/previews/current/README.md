# Current Halo UI captures

These screenshots were generated from the local Halo source with
`node scripts/capture-halo-current.cjs` using installed Chrome at 1440px and
390px. The script creates the demo project `Midnight Sessions` in a fresh,
isolated browser context; it does not touch a user's saved workspace.

The Orbital package uses the user's supplied glass-planet image, copied to
`halo/assets/halo-orbit-reference.png`, in its dashboard and Jarvis intro.
The Classic package keeps its original treatment.

The companion is shown disconnected because the capture does not pair with
the optional Windows service. The local music reference, Voicebox and Ollama
services are not connected in this static capture. These images show the UI
layout, not a claim that those services were running.
